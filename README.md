# Climate Sentiment Analysis V2 - Reddit Edition

Sistema de análisis de sentimiento sobre cambio climático utilizando publicaciones y comentarios de Reddit.

## Objetivo

Clasificar automáticamente comentarios relacionados con el cambio climático en distintas categorías mediante Machine Learning.

## Tecnologías

- Python
- Scikit-Learn
- Pandas
- NumPy
- Streamlit
- Reddit (Devvit)
- GitHub
- Google Colab

## Flujo del Proyecto

Reddit
↓
Extracción de comentarios
↓
Preprocesamiento
↓
TF-IDF
↓
Modelo Logistic Regression
↓
Clasificación
↓
Dashboard

## Categorías

- News
- Pro
- Neutral
- Anti
